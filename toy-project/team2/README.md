# [2팀] 대출 승인 예측 및 신용점수 영향력 분석

## 1. 팀원 정보

- **팀명:** 2팀
- **팀원:** 강채린, 김예지, 이연우

## 2. 프로젝트 개요 및 목적

### 대출 승인 예측 및 신용점수 영향력 분석

대출 신청자의 소득, 신용점수, 대출 금액 등 금융 정보를 활용하여 대출 승인 여부를 예측하는 **이진 분류 프로젝트**이다.

로지스틱 회귀와 랜덤 포레스트를 활용하고, 신용점수 포함 여부에 따라 총 4개 모델의 성능을 비교한다.

이를 통해 신용점수가 승인 예측에 미치는 영향과 신용점수를 제외했을 때 다른 금융 특성들의 예측력을 분석하고자 한다.

## 3. 선정 데이터셋

- **데이터셋명:** Loan Approval Prediction Dataset
- **출처:** Kaggle
- **링크:** https://www.kaggle.com/datasets/architsharma01/loan-approval-prediction-dataset
- **데이터 구성:** 4,269개 샘플의 CSV 정형 데이터
- **예측 대상:** 대출 승인 여부 (`loan_status`)
