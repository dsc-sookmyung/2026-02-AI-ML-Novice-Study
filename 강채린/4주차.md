📓 개요
- 와인 데이터(알코올·당도·pH)로 레드/화이트 와인을 분류하며 결정 트리 모델을 학습하고, 교차 검증과 하이퍼파라미터 튜닝으로 최적의 모델을 찾는 과정을 실습했다.
- 5장은 설명하기 쉬운 모델(결정 트리), 모델을 제대로 평가하고 고르는 방법(교차 검증·그리드 서치), "트리를 여러 개 묶어 성능을 높이는 방법(앙상블) 세 가지로 나눠서 정리했다.
👀 새롭게 배운 점
- 결정 트리는 예/아니오 질문으로 데이터를 나누고, 부모와 자식 노드의 불순도 차이인 정보 이득이 최대가 되도록 분할함을 목표로 함.
- 불순도(지니, 엔트로피)는 클래스 비율로만 계산하기 때문에 특성 스케일의 영향을 받지 않아 표준화가 필요 없음.
- 테스트 세트로 모델을 고르면 테스트 세트에 맞춰진 모델이 되므로, 검증 세트와 교차 검증으로 모델을 고르고 테스트 세트는 마지막에 한 번만 쓴다는 것을 알게 됨.
- 그리드 서치는 지정한 값의 모든 조합을 탐색하고, 랜덤 서치는 확률 분포에서 값을 샘플링해 더 적은 시도로 넓은 범위를 탐색함.
- 랜덤 포레스트·엑스트라 트리는 무작위성을 준 트리 여러 개의 예측을 평균하고, 그레이디언트 부스팅은 얕은 트리를 순차적으로 추가해 이전 트리의 오차를 보완함.
💡 느낀 점
- 로지스틱 회귀의 계수는 의미를 설명하기 어려웠는데, 결정 트리는 그림 하나로 분류 과정이 보여서 이해하기 쉬웠다. 루트 노드의 지니 불순도를 직접 계산해 보니 그림 속 숫자들이 어떻게 나온 값인지 알 수 있었다.
- 처음에는 검증 세트와 테스트 세트의 역할이 헷갈렸는데, 검증 세트는 "모델을 고르는 용도", 테스트 세트는 "최종 성능을 확인하는 용도"라고 생각하니 정리가 됐다.
- 앙상블로 갈수록 성능은 좋아지지만 결정 트리의 장점이던 "설명하기 쉬움"은 약해져서, 앙상블 모델을 해석하는 방법(특성 중요도, SHAP 등)도 더 알아보고 싶다.

dt = DecisionTreeClassifier(max_depth=3, random_state=42)

print(dt.score(test_input, test_target))
print(dt.feature_importances_)  # 특성 중요도 (당도가 가장 높음)

# 교차 검증 : 분류 문제는 StratifiedKFold로 클래스 비율 유지
splitter = StratifiedKFold(n_splits=10, shuffle=True, random_state=42)

# 그리드 서치 : 지정한 값의 모든 조합 탐색
params = {'min_impurity_decrease': np.arange(0.0001, 0.001, 0.0001),

gs.fit(train_input, train_target)
print(gs.best_params_)

# 랜덤 서치 : 확률 분포에서 100번 샘플링
params = {'min_impurity_decrease': uniform(0.0001, 0.001),
          'max_depth': randint(20, 50),
          'min_samples_split': randint(2, 25),
          'min_samples_leaf': randint(1, 25)}

                        n_iter=100, n_jobs=-1, random_state=42)
rs.fit(train_input, train_target)
print(rs.best_estimator_.score(test_input, test_target))

# 앙상블 : 랜덤 포레스트 / 히스토그램 기반 그레이디언트 부스팅
rf = RandomForestClassifier(oob_score=True, n_jobs=-1, random_state=42)
