📒 개요
-회귀는 예측하는데 쓰인다. 가령 60, 80, 100이 있으면 평균값인 80을 다음 값으로 예측하는 것처럼 최근접 분류 알고리즘을 사용한다. 
-knn(K 최근접 이웃 알고리즘): 표본에서 가까운 걸 k 찾기 (2단원이 분류 classifier라면, 3단원에선 예측인 Regresor을 쓴다.) 예측하려는 샘플에 가장 가까운 샘플 k개 선택 -> 샘플의 클래스 확인해 다수 클래스를 새로운 샘플의 클래스로 예측
-규제: 과적합 방지하기 위해 막는 것/ 선형 회귀 모델의 경우 기울기 작게 하기
-하이퍼파라미터: 머신러닝 알고리즘이 학습하지 않는 파라미터(암기!= 사람이 사전에 지정)

👀 새롭게 배운 점
R2: 결정계수가 0에 가까울수록 나쁜거
선형 회귀가 찾은 특성-타깃, 계수 또는 가중치에 저장됨(기울기, 절편 의미하기도)
다항회귀는 다항식을 이용해 특성고 타깃 간 관계 나타냄 -> 비선형일 수 있지만 선형 회귀로 표현 가능
모델 파라미터: 선형 회귀가 찾은 가중치처럼 머신러닝 모델이 특성에서 학습한 파라미터
하이퍼파라미터와 파라미터의 차이를 알게 됐다. 
틀성 공학: 기존의 특성을 이용해 새로운 특성 이용
💡 느낀 점 (더 알아보고 싶은 내용, 어려웠던 부분 등)
R2는 종속변수가 아닌, 종속변수가 얼마나 잘 변동하는지 알려주는 점수이다. R^2 식이 도출된 과정을 알고싶다.
