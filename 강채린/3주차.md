📓 개요
로지스틱 회귀 + 확률적 경사 하강법 + 시그모이드 함수 학습

👀 새롭게 배운 점
인공신경망의 가장 작은 단위는 로지스틱 회귀라 해도 무방하다 - 그만큼 중요함
로지스틱 회귀: 선형방정식을 학습하는 분류 알고리즘(모델)
y=1/1+e^-x
회귀: 특정 임의의 숫자 맞춤
분류: 여러 클래스 중 하나 예측
회귀, 분류는 알고리즘이 아닌 작업의 종류(모델)의미
시그모이드 함수:어떤 숫자를 넣어도 결과를 0, 1 사이로 바꿔주는 s모양 함수 
로지스틱은 매개변수로 규제 효과를 낼 수 있다.
(사이킷런에서 구현 가능-c가 클수록 규제 커짐)

predict() vs predict_proba() 
predict_proba(): 결과만(확률)
predict: 최종 예측 뭐 선택

소프트맥스 vs 시그모이드
소프트맥스 - 여러 개 클래스(3개이상)
시그모이드 - 보통 2개 클래스
손실함수 - 산 

SGD: 모델 오답을 줄이기 위해 가중치를 수정해 나가는 방법 


# 로지스틱 함수 그리기
import numpy as np
import matplotlib.pyplot as plt

# x 값 생성 
# -10부터 10까지 500개의 숫자를 균일하게 생성 + x축에 사용할 값 만들기
x = np.linspace(-10, 10, 500) 

# 로지스틱 함수-np.exp()는 자연상수 e의 지수값을 계산
y = 1 / (1 + np.exp(-x))

# 그래프 그리기
plt.plot(x, y)

# 그래프 설정
plt.xlabel("x") /*이름설정*/
plt.ylabel("P(y=1)")
plt.title("Logistic Regression Function")

# 격자 표시
plt.grid(True)

# 그래프 출력
plt.show()

💡 느낀 점
처음에는 로지스틱 회귀와 시그모이드 함수, predict_proba()가 각각 어떤 역할을 하는지 헷갈렸다. 강의를 보면서 시그모이드는 값을 0~1 사이의 확률로 변환하는 함수이고, predict_proba()는 모델이 예측한 각 클래스의 확률을 확인하는 함수라는 것을 알게 되었다. 특히 머신러닝 라이브러리를 사용하는 것에 그치지 않고 그 안에서 어떤 수학적 원리가 사용되는지 이해하는 것이 중요하다고 느꼈다. 이전에는 머신러닝에서 모델을 학습시킨다는 것이 단순히 데이터를 넣고 결과를 얻는 과정이라고 생각했다. 하지만 확률적 경사 하강법을 배우면서 예측하고, 오차를 확인하고, 가중치를 수정하는 과정을 반복하면서 모델이 학습된다는 것을 알게 되었다. 특히 데이터를 조금씩 사용하면서 학습할 수 있다는 점이 인상적이었다.

-로지스틱 회귀 (전체 요리법)
요리법에 사용되는 재료의 손질법- 소프트맥스 시그모이드 


❤️ 한 줄 요약 
데이터
 ↓
로지스틱 회귀
 ↓
가중치 × 입력 + 편향
 ↓
시그모이드(이진, 다중은 소프트맥스)
 ↓
확률 계산
 ↓
오차 계산
 ↓
확률적 경사 하강법
 ↓
가중치 수정
 ↓
다시 학습

❣️요약을 코드로(scikit-learn 사용X)
import numpy as np

# =========================
# 1. 데이터
# =========================
X = np.array([
    [1],
    [2],
    [3],
    [4],
    [5]
])

y = np.array([0, 0, 0, 1, 1])


# =========================
# 2. 가중치와 편향 초기화
# =========================
w = 0.0
b = 0.0

learning_rate = 0.1


# =========================
# 3. 시그모이드 함수
# =========================
def sigmoid(z):
    return 1 / (1 + np.exp(-z))


# =========================
# 4. 학습
# =========================
for epoch in range(1000):

    # 가중치 × 입력 + 편향
    z = X * w + b

    # 시그모이드 → 확률
    y_pred = sigmoid(z)

    # 오차를 이용해 가중치와 편향의 기울기 계산
    dw = np.mean(X * (y_pred - y.reshape(-1, 1)))
    db = np.mean(y_pred - y)

    # 가중치 수정
    w = w - learning_rate * dw
    b = b - learning_rate * db


# =========================
# 5. 학습 결과 확인
# =========================
print("가중치:", w)
print("편향:", b)

# 새로운 데이터
new_X = np.array([[6]])

# 가중치 × 입력 + 편향
z = new_X * w + b

# 시그모이드 → 확률
probability = sigmoid(z)

print("1일 확률:", probability[0][0])
