## 📒 개요
- 힌빛 마켓의 상황을 예시로 들어 비지도 학습에 대해 공부했다.
- 비지도 학습의 개념을 배우고, 대표적인 비지도 학습인 군집, k-평균 알고리즘이 어떤 원리와 방식으로 작동하며 이를 어떤 함수를 활용해 구현할 수 있는지 학습했다.

## 👀 새롭게 배운 점
- numpy 안의 절댓값을 계산하는 함수인 abs()를 통해 절댓값 오차를 구하고 가장 가까운 사진을 고름으로써 비지도 학습을 시킬 수 있다는 것을 알게 되었다. 또한, axis 지정, mean을 통한 평균 계산, subplots()를 통해 여러개의 그래프를 배열처럼 쌓는 법 등 다양한 함수의 사용법을 알 수 있었다.
- k-평균 알고리즘에서 k-평균 군집 알고리즘이 평균을 자동으로 찾아주고, sklearn.cluster 모듈 아래 KMeans 클래스를 통해 k-평균 알고리즘을 구현할 수 있다는 것을 알게 되었다. 더불어, n_clusters로 클러스터의 개수를 지정할 때 이너셔를 활용하는 방법인 엘보우 방법을 이용하여 최적의 클러스터 개수를 찾을 수 있다는 것을 알게 되었다.
- 특성을 차원이라고도 부르며, 과대적합 문제 등의 이유로 데이터를 가장 잘 나타내는 일부 특성을 선택해 데이터 크기를 줄이고 모델의 성능을 향상시킬 수 있는 방법인 차원축소에 대해 알게 되었다.

## 💡 느낀 점 (더 알아보고 싶은 내용, 어려웠던 부분 등)
- 1학기 수업시간에 비지도 학습에 대한 개념은 배웠지만 코드로 구현해보지는 못했었는데 이번 기회로 구현해볼 수 있어서 유익했고, 예시에서 그래프를 배열처럼 구현해 시각화시켜 설명하여 이해가 잘 됐다. 하지만, 코드의 세세한 부분이나 예시에서 설명해주지 않은 파라미터 조정 등은 단번에 이해가 잘 되지 않아 어려웠다.

```python
"""# 군집 알고리즘"""
"""## 과일 사진 데이터 준비하기"""

!wget https://bit.ly/fruits_300_data -O fruits_300.npy

import numpy as np
import matplotlib.pyplot as plt

fruits = np.load('fruits_300.npy')

print(fruits.shape)

print(fruits[0, 0, :])

plt.imshow(fruits[0], cmap='gray_r')
plt.show()

fig, axs = plt.subplots(1, 2)
axs[0].imshow(fruits[100], cmap='gray_r')
axs[1].imshow(fruits[200], cmap='gray_r')
plt.show

"""## 픽셀값 분석하기"""

apple = fruits[0:100].reshape(-1, 100*100)
pineapple = fruits[100:200].reshape(-1, 100*100)
banana = fruits[200:300].reshape(-1, 100*100)

print(apple.shape)

print(apple.mean(axis=1))

plt.hist(apple.mean(axis=1), alpha=0.8)
plt.hist(pineapple.mean(axis=1), alpha=0.8)
plt.hist(banana.mean(axis=1), alpha=0.8)
plt.legend()
plt.show()

fig, axs = plt.subplots(1, 3, figsize=(20, 5))
axs[0].bar(range(10000), apple.mean(axis=0))
axs[1].bar(range(10000), pineapple.mean(axis=0))
axs[2].bar(range(10000), banana.mean(axis=0))
plt.show()

apple_mean = apple.mean(axis=0).reshape(100, 100)
pineapple_mean = pineapple.mean(axis=0).reshape(100, 100)
banana_mean = banana.mean(axis=0).reshape(100, 100)

fig, axs = plt.subplots(1, 3, figsize=(20, 5))
axs[0].imshow(apple_mean, cmap='gray_r')
axs[1].imshow(pineapple_mean, cmap='gray_r')
axs[2].imshow(banana_mean, cmap='gray_r')
plt.show()


"""## 평균값과 가까운 사진 고르기"""

abs_diff = np.abs(fruits - apple_mean)
abs_mean = np.mean(abs_diff, axis=(1, 2))
print(abs_mean.shape)

apple_index = np.argsort(abs_mean)[:100]
fig, axs = plt.subplots(10, 10, figsize=(10, 10))
fig, axs = plt.subplots(10, 10, figsize=(10, 10))
for i in range(10):
    for j in range(10):
        axs[i, j].imshow(fruits[apple_index[i*10 + j]], cmap='gray_r')
        axs[i, j].axis('off')
plt.show()
```
