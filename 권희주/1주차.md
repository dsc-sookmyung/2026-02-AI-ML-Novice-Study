# [1주차] AI/ML과 과적합, 과소적합
 
## 1. 인공 지능의 역사
 
| 시기 | 주요 내용 |
|---|---|
| 1940~1950년대 | 인공 뉴런 모델(1943), 튜링 테스트(1950), 다트머스 회의에서 'AI' 용어 등장(1956), 퍼셉트론(1958) |
| 1970년대 | 퍼셉트론의 XOR 문제 한계 증명(1969) → **첫 번째 AI 겨울** |
| 1980년대~1990년대 초 | 전문가 시스템 유행, 역전파 알고리즘(1986) → 유지 비용 문제로 **두 번째 AI 겨울** |
| 1990년대~2000년대 | 데이터에서 규칙을 찾는 **머신 러닝**이 중심, 딥 블루의 체스 승리(1997) |
| 2010년대 | 딥 러닝 부상(2006), AlexNet(2012), 알파고(2016) |
| 2017년~현재 | 트랜스포머(2017), ChatGPT 공개(2022) → **생성형 AI** 대중화 |
 
## 2. 인공 지능과 머신 러닝
 
- **인공 지능(AI)** : 컴퓨터가 인간의 학습, 문제 해결, 의사 결정 등을 모방하도록 하는 기술
- **머신 러닝(ML)** : 명시적인 프로그래밍 없이 데이터로부터 학습해 예측·결정을 내리는 기술
- **딥 러닝(DL)** : 여러 층의 신경망을 깊게 쌓아 복잡한 패턴을 학습하는 머신 러닝의 한 분야
- **생성형 AI** : 딥 러닝을 기반으로 새로운 콘텐츠를 만들어내는 기술
> AI ⊃ ML ⊃ DL ⊃ 생성형 AI
 
## 3. 머신 러닝의 학습 방법
 
| 학습 방법 | 데이터 | 특징 | 예시 |
|---|---|---|---|
| 지도 학습 | 정답 있음 | 정답과 함께 학습해 예측 | 스팸 필터링, 이미지 분류, 질병 진단 |
| 비지도 학습 | 정답 없음 | 숨은 패턴을 찾거나 그룹화 | 고객 세분화, 이상치 탐지, 군집화 |
| 강화 학습 | 환경과 보상 | 시행착오로 보상을 최대화 | 알파고, 로봇 공학 |
 
## 4. 데이터셋 분할 (6:2:2 또는 7:1.5:1.5)
 
- **훈련 세트 (60~80%)** : 모델이 패턴을 학습하는 데이터
- **검증 세트 (10~20%)** : 중간 점검 및 하이퍼파라미터 튜닝용 데이터
- **테스트 세트 (10~20%)** : 최종 성능 평가용 데이터
  - 테스트 결과를 보고 모델을 고치면 테스트 데이터에도 과적합되므로, **마지막에 한 번만** 사용
## 5. 과적합과 과소적합
 
### 편향과 분산
 
- **Bias(편향)** : 모델의 예측이 실제 값과 평균적으로 얼마나 벗어나는가 → 크면 **과소적합**
- **Variance(분산)** : 학습 데이터가 바뀔 때 예측이 얼마나 흔들리는가 → 크면 **과적합**
- **편향-분산 트레이드오프** : 모델을 복잡하게 하면 편향↓ 분산↑, 단순하게 하면 편향↑ 분산↓
  → 최적의 모델은 둘의 **균형**에서 달성

### 과적합 (Overfitting)
 
모델이 너무 복잡해 훈련 데이터의 노이즈까지 외워버린 상태
→ 훈련 오차는 낮지만 테스트 오차가 높음
 
**원인** : 너무 복잡한 모델, 작거나 노이즈가 많은 데이터

### 과소적합 (Underfitting)
 
모델이 너무 단순해 데이터의 기본 패턴조차 학습하지 못한 상태
→ 훈련 오차와 테스트 오차 모두 높음
 
**원인** : 너무 단순한 모델, 부족한 특성, 과도한 규제, 짧은 학습 시간

### 비교
 
| | 과소적합 | 적절 | 과적합 |
|---|---|---|---|
| 훈련 오차 | 높음 | 낮음 | 매우 낮음 |
| 테스트 오차 | 높음 | 낮음 | 높음 |
| 원인 | 높은 편향 | 균형 | 높은 분산 |
| 모델 복잡도 | 너무 단순 | 적절 | 너무 복잡 |
 
## 6. 해결방법
 
### 과소적합
- 파라미터가 더 많은 복잡한 모델 선택
- 규제 하이퍼파라미터 값 줄이기
- 학습 시간(Epoch) 늘리기
- 유의미한 특성(Feature) 추가

### 과적합
- 데이터 개수 늘리기
- 특성(Feature) 개수 줄이기
- 훈련 데이터의 잡음 줄이기
- **K-fold 교차 검증** : 훈련/검증 세트를 여러 번 나누어 모델 검증
- **조기 종료(Early Stopping)** : 검증 성능이 더 이상 좋아지지 않을 때 학습 중단
- **정칙화(Regularization)** : 가중치가 지나치게 커지지 않도록 제한
  - L1 규제(Lasso) : 불필요한 가중치를 0으로 만들어 중요한 특성만 남김
  - L2 규제(Ridge) : 가중치를 전체적으로 작게 만들어 모델을 부드럽게 만듦

 
> 머신 러닝에서 중요한 것은 **"얼마나 잘 외웠는가"가 아니라 "얼마나 잘 일반화하는가"**이다.
