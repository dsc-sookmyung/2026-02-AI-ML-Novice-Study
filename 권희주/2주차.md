## 📒 개요
- 회귀 알고리즘과 모델 규제를 학습하며 k-최근접 이웃 회귀, 선형 회귀, 다항 회귀, 다중 회귀를 농어 데이터로 실습했다.
- 특성 공학으로 특성을 늘렸을 때 생기는 과대적합을 직접 확인하고, 표준화 후 릿지·라쏘 규제와 alpha 값 조정으로 이를 해결하는 과정을 정리했다.

## 👀 새롭게 배운 점
- 분류가 정해진 클래스를 맞히는 문제라면, 회귀는 무게처럼 임의의 숫자를 예측하는 문제이다. k-최근접 이웃 회귀는 이웃의 평균으로 예측하기 때문에 훈련 데이터 범위를 벗어난 큰 농어의 무게를 제대로 예측하지 못하고, 선형 회귀·다항 회귀는 이 한계를 보완할 수 있다.
- PolynomialFeatures로 degree=5까지 특성을 늘리면 특성이 55개로 샘플 수(42개)보다 많아져, 훈련 점수는 거의 1.0인데 테스트 점수는 약 -144까지 떨어지는 극단적인 과대적합이 일어난다.
- 규제는 계수 크기에 벌칙을 주는 방식이라 특성의 스케일이 다르면 공정하게 적용되지 않기 때문에, 규제 전에 반드시 훈련 세트 기준으로 표준화해야 한다.
- 릿지(L2)는 계수를 0에 가깝게 줄이고, 라쏘(L1)는 계수를 아예 0으로 만들 수 있다.
- alpha는 모델이 학습하는 값이 아니라 사람이 정하는 하이퍼파라미터이다. alpha가 작으면 과대적합, 크면 과소적합이 되며, 여러 값을 넣어 훈련·테스트 점수를 비교해 최적값을 찾는다(릿지 0.1, 라쏘 10).

## 💡 느낀 점 (더 알아보고 싶은 내용, 어려웠던 부분 등)
- 1주차에 과적합과 과소적합을 탐구하면서 해결 방법으로 릿지 회귀와 라쏘 회귀를 간단히만 살펴봤었는데, 이번 강의에서 표준화부터 규제 적용, alpha 조정까지 직접 실습해보니 규제가 어떻게 과적합을 막는지 훨씬 잘 이해할 수 있었다.
- 개념으로만 정리했던 편향-분산 트레이드오프도 alpha 값에 따라 훈련·테스트 점수가 벌어지고 좁혀지는 그래프로 직접 확인할 수 있어서 이해가 훨씬 구체적이 되었다.
- 책과 똑같이 코드를 작성했는데도 결과가 달라서 어려웠다. 최신 사이킷런에서는 `get_feature_names()`가 `get_feature_names_out()`으로 바뀌었고, `LinearRegression`에 `tol` 옵션이 생겨 degree=5에서도 과대적합이 거의 나타나지 않았다(`tol=0`으로 설정하면 책과 같은 결과). 라이브러리 버전이 결과에 영향을 줄 수 있다는 점을 알게 되었다.


## 💻 실습 코드
```python
import numpy as np
import matplotlib.pyplot as plt
from sklearn.model_selection import train_test_split
from sklearn.neighbors import KNeighborsRegressor #추정기
from sklearn.metrics import mean_absolute_error

perch_length = np.array([8.4, 13.7, 15.0, 16.2, 17.4, 18.0, 18.7, 19.0, 19.6, 20.0, 21.0,
       21.0, 21.0, 21.3, 22.0, 22.0, 22.0, 22.0, 22.0, 22.5, 22.5, 22.7,
       23.0, 23.5, 24.0, 24.0, 24.6, 25.0, 25.6, 26.5, 27.3, 27.5, 27.5,
       27.5, 28.0, 28.7, 30.0, 32.8, 34.5, 35.0, 36.5, 36.0, 37.0, 37.0,
       39.0, 39.0, 39.0, 40.0, 40.0, 40.0, 40.0, 42.0, 43.0, 43.0, 43.5,
       44.0])

perch_weight = np.array([5.9, 32.0, 40.0, 51.5, 70.0, 100.0, 78.0, 80.0, 85.0, 85.0, 110.0,
       115.0, 125.0, 130.0, 120.0, 120.0, 130.0, 135.0, 110.0, 130.0,
       150.0, 145.0, 150.0, 170.0, 225.0, 145.0, 188.0, 180.0, 197.0,
       218.0, 300.0, 260.0, 265.0, 250.0, 250.0, 300.0, 320.0, 514.0,
       556.0, 840.0, 685.0, 700.0, 700.0, 690.0, 900.0, 650.0, 820.0,
       850.0, 900.0, 1015.0, 820.0, 1100.0, 1000.0, 1100.0, 1000.0,
       1000.0])

train_input, test_input, train_target, test_target = train_test_split(perch_length, perch_weight, random_state=42)

train_input = train_input.reshape(-1, 1)
test_input = test_input.reshape(-1, 1)

knr = KNeighborsRegressor()
knr.fit(train_input, train_target)

knr.score(test_input, test_target)

knr.n_neighbors = 3
knr.fit(train_input, train_target)

print(knr.score(train_input, train_target))
print(knr.score(test_input, test_target))

print(knr.predict([[50]]))

#50cm 농어의 이웃을 구함
distance, indexes = knr.kneighbors([[50]])

#훈련 세트의 산점도를 그림
plt.scatter(train_input, train_target)
#훈련 세트 중에서 이웃 샘플만 다시 그림
plt.scatter(train_input[indexes], train_target[indexes], marker='D')

#50cm 농어 데이터
plt.scatter(50, 1033, marker='^')
plt.show()

#선형 회귀(linear regression) : 직선으로 데이터를 근사화하는 회귀 알고리즘

from sklearn.linear_model import LinearRegression

lr = LinearRegression()
#선형 회귀 모델 훈련
lr.fit(train_input, train_target)

#50cm 농어에 대한 예측
#y축 : 농어 무게, x축 : 농어 길이
#농어 무게 = lr.coef_(기울기) * 농어 길이 + lr.intercept_(y절편)
print(lr.predict([[50]]))

print(lr.coef_, lr.intercept_)

#훈련 세트의 산점도를 그림
plt.scatter(train_input, train_target)
#15에서 50까지 1차 방정식 그래프를 그림
plt.plot([15, 50], [15 * lr.coef_ + lr.intercept_, 50 * lr.coef_ + lr.intercept_])

#50cm 농어 데이터
plt.scatter(50, 1241, marker='^')
plt.show()

print(lr.score(train_input, train_target))
print(lr.score(test_input, test_target))

#다항 회귀
train_poly = np.column_stack((train_input ** 2, train_input))
test_poly = np.column_stack((test_input ** 2, test_input))

lr.fit(train_poly, train_target)

print(lr.predict([[50 ** 2, 50]]))

print(lr.coef_, lr.intercept_)

#구간별 직선을 그리기 위해 15에서 49까지 정수 배열을 만듦
point = np.arange(15, 50)

#훈련 세트의 산점도를 그림
plt.scatter(train_input, train_target)

#15에서 49까지 2차 방정식 그래프를 그림
plt.plot(point, 1.01*point**2 - 21.6*point + 116.05)

#50cm 농어 데이터
plt.scatter([50], [1574], marker='^')
plt.show()

print(lr.score(train_poly, train_target))
print(lr.score(test_poly, test_target))
```
